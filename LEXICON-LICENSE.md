# Lexique français

Le jeu charge le paquet [`an-array-of-french-words`](https://github.com/words/an-array-of-french-words), une liste d’environ 336 000 mots français dérivée de la liste Letterpress.

- Source : Zeke Sikelianos, dépôt GitHub `words/an-array-of-french-words`
- Licence : MIT
- Le paquet est déclaré comme dépendance npm et est chargé localement au démarrage ; aucune API externe n’est appelée pour valider les propositions.

Le texte de la licence MIT est fourni par le paquet installé dans `node_modules/an-array-of-french-words/license`.
